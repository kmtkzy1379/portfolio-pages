# 小松 主弥 ポートフォリオ（8bit RPG UI）

白黒8ビットのRPGゲーム選択画面ふうのポートフォリオサイト。
ビルド不要の静的サイト（HTML / CSS / 素のJS）で、そのまま GitHub Pages に置けます。

## 動かす

```bash
# このフォルダで
python -m http.server 8000
# → http://127.0.0.1:8000/
```

`index.html` を直接ダブルクリックしても動きますが、動画やlocalStorageの挙動が
ブラウザによって制限されるため、確認はローカルサーバー経由を推奨。

## ファイル構成

```
index.html            画面の骨格（ローディング / HUD / 演出レイヤー）
assets/css/style.css  8bit UI のスタイル（テーマ変数・ウィンドウ・演出）
assets/js/data.js     ★ 本文データ。原稿を直すときはここだけ触る
assets/js/app.js      画面遷移・ゲージ・サウンド・カウンター・演出
images/               作品のスクリーンショット・動画
Talk-AI-images/       Talk AI のアイコンと「おとも」の元絵（1708×2048 / 1枚2MB前後）
Talk-AI-images/web/   ↑ を整えた配信用。サイトが読むのはこちら（.webp）
tools/build-mascot.ps1  おとものフレームを web/ に作り直すツール
ButtonSound/          決定音・キャンセル音
icon.png              PromptLore のアイコン（作品ページ内でのみ使用）
```

`Talk-AI-images/web/` には同じ絵の `.png` も置いてあります（差し替え用の中間ファイル）。
サイトが実際に読み込むのは `.webp` だけなので、`.png` は転送されません。
キャラのフレームは **332×420**、アイコンは 384×384 です。

### おともの元絵を描き直したとき

```powershell
powershell -ExecutionPolicy Bypass -File tools/build-mascot.ps1
```

`Talk-AI-images/` の5枚を読んで `Talk-AI-images/web/` を作り直します
（Windows と `cwebp` が必要）。**元絵を差し替えるたびに実行してください。**
最後に出る `aspect-ratio: 332 / 420;` を `style.css` の `.mascot__btn` に反映します。

なぜ必要かというと、元絵（`idel` `yure1` `yure2` `mabataki1` `mabataki2`）は
**1枚ずつ書き出したせいで、キャラの大きさと位置がバラバラ**だからです。そのまま
切り替えると、動くたびに画面上でキャラが跳ねます。ツールがやっているのは次の4つ。

1. **背景を透過にする** … 元絵の背景は透明ではなく *不透明な黒* でした。画面のふちから
   黒い部分を塗りつぶし式にたどってアルファ0にしています（キャラの周りに明るい縁取りが
   あるので、衣装の黒は塗りつぶされません）。境界は明るさに応じて半透明にしてなじませます
2. **ゴミを消す** … 書き出しのときに入った数十ピクセルの浮きカスを除去
3. **`idel` に合わせて拡大率と位置をそろえる** … 下半身を手がかりに相互相関で
   `(拡大率, 横ズレ, 縦ズレ)` を探索。今の元絵では `idel` を基準に **yure1=0.952 /
   yure2=0.898 / mabataki1=0.940 / mabataki2=0.930**、つまり他の4枚は5〜10%小さく
   書き出されていました
4. **5枚の共通範囲で切り抜いて 332×420 に縮小** → ロスレス webp

この整列で、足元の位置のばらつきは **112px → 9px**（元絵の解像度で）に収まりました。
理想は、元絵を最初から同じ倍率・同じ位置・透過背景で書き出すことです。そうすれば
この工程は単純な縮小だけで済みます。

なお `Talk-AI-8bit-icon`（Talk AI のアイコン）はアニメーションしない別素材なので、
このツールの対象外です。元から透過なので、差し替えるときは 384×384 に縮めるだけで足ります。

サイトのファビコンは `index.html` 内にドット絵のSVGを直接埋め込んでいます
（PromptLore のアイコンとは別物）。

## 画面の流れ

```
ローディング → サイトカウンター +1 → 自己紹介
                                        ↓ スワイプ / タップ
                                     メニュー
                            ┌───────────┼───────────┐
                         さくひん   インターン・活動   せってい
                            ↓
                        各作品の詳細

HUD の「記」ボタン → 小松の記憶（閲覧の記録）→ 各項目へジャンプ
```

- キーボード：`↑↓` カーソル移動／`Enter` 決定／`Esc` もどる
- スマホ：左スワイプで先へ、右スワイプで戻る
- 直リンク：`#/works/talkai` / `#/intro/selfpr` / `#/history/relic` は
  その項目を開いた状態でスクロールして表示します

## 閲覧ゲージと隠しメッセージ（小松の記憶）

- 閲覧対象は **15項目**（自己紹介3 + 作品7 + 活動履歴5）
- 1項目読むごとに `+1 EXP` とゲージが増え、LVが上がる
- どこを読んだかは **HUDの「記」ボタン**（レベルバーの右）か
  **設定 →「小松の記憶（閲覧の記録）」** から一覧できる。未読の項目を選ぶとそこへ飛ぶ
- 15/15 で隠しメッセージ「全て読んで頂きありがとうございます！これであなたは小松マスターです。」＋ファンファーレ・紙吹雪
- 進捗は localStorage（`kzy.progress.v1`）に保存。設定の「小松の記憶 を けす」でリセット

項目を増やしたい場合は `data.js` の `works` / `history` / `introItems` に足すだけで、
ゲージの分母（`DATA.allItemIds`）は自動で追従します。

## ドット絵スプライト

画像のない作品は、`data.js` の `DATA.sprites` に書いたドット絵を表示します
（`#` = 明るい色 / `+` = 中間色 / `.` = 背景。24×24 で全行同じ長さにする）。

- 作品に `sprite: 'myai'` を付けると一覧のサムネイルに使われる
- 本文中に出したいときは `{ type: 'sprite', art: 'myai', caption: '…' }`
- `DATA.sprites` に無い作品は、IDから左右対称のドット絵を自動生成します

手描きの `myai` スプライト（ヘッドセットのキャラ）は My-AI のサムネイルです。
Talk AI は画像アイコン `Talk-AI-images/web/Talk-AI-8bit-icon.webp` を使っています。

## おとも（画面端のドット絵キャラ）

画面の右下に立って、ときどき ゆれたり まばたきしたりします。GIF ではなく
静止画5枚を `app.js` の `Mascot` が切り替えているので、コマの速さや出る頻度は
コードで調整できます（`MASCOT_SWAY` / `MASCOT_BLINK` / `Mascot.schedule`）。

| 動き | コマの順番 |
|---|---|
| 右に ゆれる | idel → yure1 → yure2 → idel |
| 左に ゆれる | idel → yure1（左右反転）→ yure2（左右反転）→ idel |
| まばたき | idel → mabataki1 → mabataki2 → mabataki1 → idel |

ずっとループはせず、1.6〜5.2秒の待機をはさんで上のどれか1回だけを再生します
（右30% / 左30% / まばたき40%）。設定の「アニメーション」が OFF のときは
idel で止まります。

出る場所は段階的に増えます。

1. **なかまにする前** … Talk AI の詳細ページ（`#/works/talkai`）と、小松マスターの画面だけ
2. **小松マスターの画面の おとも をクリック** … 「クリック！▼」が出ている状態で押すと なかまになる
3. **なかまにした後** … 全画面に出るようになり、設定に「おとも」の行が現れて ON/OFF できる

なかまにしたかどうかは `kzy.progress.v1` の `mascot`、ON/OFF は `kzy.settings.v1` の
`mascot` に入ります。**設定の「小松の記憶 を けす」を実行すると、小松マスターと一緒に
おとも も未取得に戻ります。**

フレーム画像は「初めて表示するとき」に JS が `<img>` を作って読み込みます。
Talk AI と小松マスターに来ない人には1バイトも転送されません。

## サイトカウンター

既定は **サーバー不要のローカルカウンター**で、そのブラウザでの来訪回数を数えます
（表示は「あなたの アクセス： N かいめ」）。

サイト全体の通算訪問者数にしたい場合は `assets/js/app.js` 冒頭の `CONFIG.counter` を変更します。

```js
counter: {
  driver: 'remote',
  endpoint: 'https://<カウンターAPIのURL>',  // GET すると { "count": 1234 } が返るもの
  countPath: 'count',
  digits: 6
}
```

`driver: 'remote'` にすると表示が「あなたは N 人目の 訪れた人 です」に変わります。
通信に失敗した場合は自動でローカルカウンターにフォールバックするので、表示が壊れることはありません。

## 設定でできること

| 項目 | 既定値 | 内容 |
|---|---|---|
| こうかおん（SE） | **OFF** | いきなり音が鳴って驚かないよう既定OFF。HUDの ♪ でも切り替え |
| アニメーション | ON | 点滅・スクロール演出。OSの「視差効果を減らす」が有効なら初回OFF |
| がめん | くろ | くろ（ダーク）／しろ（ライト） |
| スクリーンショット | **カラー** | 元のカラー／モノクロ（8bit寄せ） |
| そうさせん | ON | ブラウン管風の走査線 |
| おとも | ON | 画面のはしのキャラ。**なかまにするまで行そのものが出ない** |
| 小松の記憶 | — | 閲覧の記録一覧へ |
| 小松の記憶 を けす | — | 閲覧の記録をリセット（2回押しで確定） |

設定は localStorage（`kzy.settings.v1`）に保存されます。
